# FreelanceHub Frontend Development Plan

## Overview
This document outlines the work division for the 4-person frontend team.
**Tech Stack:** ONLY HTML, CSS, and JavaScript. No frameworks or libraries are allowed.

## Work Breakdown

### 🧑‍💻 Person 1: Project Setup, Navigation, and Hero Section
* **Project Initialization:** Set up index.html, styles.css, and main.js.
* **Global Header:** Build the navigation bar using plain HTML/CSS and ensure it is responsive.
* **Hero Section:** Build the main headline, the toggle using JS logic, the search input, and the tags.

### 🧑‍💻 Person 2: Categories & Freelancer Cards
* **Browse Categories Section:** Build the grid of category cards using pure CSS.
* **All Categories Modal:** Implement the interaction where clicking View all opens a modal overlay using HTML, CSS, and JS.
* **Top Talent Section:** Build the freelancer profile cards.
* **Card Interactions:** Implement the hover effects on these cards using CSS.

### 🧑‍💻 Person 3: Process Flow & CTA Blocks
* **How Works Section:** Build the process steps in HTML.
* **Accordion Logic:** Write JS to handle the expand/collapse interaction for the Process Steps accordion.
* **Client vs. Freelancer Cards:** Build the large feature blocks using HTML and CSS.

### 🧑‍💻 Person 4: Trust Elements, Imagery, and Footer
* **Image Cluster:** Build the image collage section using CSS positioning.
* **Stats Section:** Build the logo cloud and the metric cards.
* **Global Footer:** Build the footer layout using HTML/CSS.
* **Footer Interactions:** Implement the modal that triggers when a footer link is clicked using JS.

## Team Guidelines
1. **CSS Files:** Use separate CSS files for each section if needed and import them into a main stylesheet.
2. **Mock Data:** Have one person create a shared data.js file with JavaScript objects containing fake data.
