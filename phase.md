# FreelanceHub Development Phases

This document outlines the step-by-step development phases for the frontend team using ONLY pure HTML, CSS, and JavaScript.

## Phase 1: Foundation & Setup
* **Person 1:** Set up the standard index.html boilerplate, and link the global styles.css and main.js.
* **Person 2:** Create a shared data.js file with JS objects containing dummy data.
* **Person 3 & 4:** Set up a clean folder structure (css, js, images).

## Phase 2: Building Independent HTML/CSS Sections
* **Person 1:** Build the Navbar HTML/CSS and the Hero Section HTML/CSS.
* **Person 2:** Build the Category Cards and Freelancer Profile Cards HTML/CSS.
* **Person 3:** Build the Process Steps HTML/CSS and the CTA cards.
* **Person 4:** Build the Image Cluster HTML/CSS, Stats Cloud, and the Global Footer.

## Phase 3: JavaScript Interactivity
* **Person 1:** Write the JS for the toggle switch.
* **Person 2:** Write the JS to dynamically render freelancer cards from data.js, and build the modal toggle logic.
* **Person 3:** Implement the JS expand/collapse logic for the Process Steps accordion.
* **Person 4:** Wire up the modal to trigger on footer links using JS event listeners.

## Phase 4: Assembly & Integration
* **All Team Members:** Combine HTML structure and CSS classes.

## Phase 5: Polish and Testing
* **Responsive Audit:** Test the site on mobile, tablet, and desktop views.
* **Final Check:** Ensure all HTML, CSS, and JS is functioning correctly together without any external tools.
